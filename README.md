# speedio

an app that tells you how fast you're going and warns you when you're speeding. works on your phone and in carplay. that's basically it.

## what you need

- a mac with xcode
- an iphone (or the simulator)

## how to run it

1. open the project in xcode. like, double click the workspace file or whatever.
2. pick your phone (or simulator) up top.
3. hit the play button.
4. that's it. it should build and run.

## how to use it

- open the app. it shows your speed and the speed limit.
- if you go over the limit, it beeps and vibrates so you know.
- you can also search for a place to drive to and it'll give you turn by turn directions, like "in 800 ft turn right."

## how to set the speed limit stuff

honestly just use the default settings. if you want to change stuff, there's a settings screen in the app. you can't really break anything, so go wild.
